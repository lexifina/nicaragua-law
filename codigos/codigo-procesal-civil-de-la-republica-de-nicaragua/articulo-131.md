# Artículo 131

Plazo y término

Plazo, es el período de tiempo entre dos fechas en que se puede realizar válidamente una actuación procesal.

Término, es el día, y en su caso hora fijada, dentro del plazo en que se debe realizar el acto procesal ordenado.

Cuando en este Código se indique que una actuación debe hacerse “inmediatamente” o “tan pronto” o no exista plazo o término fijado para su realización, se entenderá que debe realizarse dentro de las siguientes veinticuatro horas.
