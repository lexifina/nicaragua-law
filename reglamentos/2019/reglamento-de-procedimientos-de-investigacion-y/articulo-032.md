# Artículo 32

Preclusión de plazos y términos

Transcurrido el plazo o pasado el término señalado para la realización de un acto procedimental y este no se efectuase, se entenderá irrevocablemente precluido, salvo Caso Fortuito o causa de Fuerza Mayor, apreciado por el Tribunal de Honor u órgano competente.
