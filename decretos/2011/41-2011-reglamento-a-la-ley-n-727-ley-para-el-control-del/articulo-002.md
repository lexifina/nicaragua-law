# Artículo 2

Uso de Términos

Para efectos del presente Reglamento, cuando se utilice la palabra Ley, deberá entenderse que se está haciendo referencia a la Ley Nº. 727, Ley para el control del Tabaco, asimismo, cuando se cite la palabra Reglamento, se entenderá que se refiere al presente Decreto y cuando se utilice la sigla MINSA se entenderá que se refiere al Ministerio de Salud.
