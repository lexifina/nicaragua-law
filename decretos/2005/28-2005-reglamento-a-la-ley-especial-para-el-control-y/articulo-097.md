# Artículo 97

Información para registro de tipos de explosivos.

Previo a toda autorización para importación, fabricación y/o comercialización de explosivos, artefactos pirotécnicos o materiales relacionados, los interesados deberán solicitar a la DAEM el registro de los tipos de explosivos, para lo cual, remitirán a la autoridad de aplicación los datos siguientes:

1. Fábrica que lo produce

2. Designación y marca del explosivo

3. Características

4. Datos de sus componentes

5. Acondicionamiento y embalaje

6. Usos y aplicaciones

7. Muestra del explosivo

8. Otros datos de interés para el registro
