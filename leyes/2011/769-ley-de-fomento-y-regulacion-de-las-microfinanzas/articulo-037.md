# Artículo 37

Equipo de Investigación para Promoción de las Microfinanzas

La CONAMI podrá conformar equipos técnicos o contratar consultorías para la investigación de temas relacionados con la promoción de microfinanzas, así como el desarrollo de estudios y metodologías que servirán de insumo para la elaboración de las estrategias de promoción al microcrédito y como base de consulta para las IMF registradas.
